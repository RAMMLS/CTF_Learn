**Сокет** - программный интерфейс для обмена данными между процессами. На транспортном уровне [[TransportLayer]] сокеты позволяют приложениям использовать протоколы TCP & UDP для передачи данных.

Сокет - построенный на транспортном уровне канал, по которому передается информация.

## Типы сокетов: 
- Потоковые (SOCK_STREAM) - используют TCP, гарантируют надежность передачи
- Дейтаграммные (SOCK_DGRAM) - используют UDP, быстрая передача без гарантий


**Сокет в сети однозначно идентифицируется парой IP:port**


## Telnet 

**Telnet** - текстовый сетевой протокол, который выполняет подключение к  удаленному терминалу по TCP. 

**В настоящее время не используется**

### netcat

**netcat** — утилита, позволяющая подключаться к сокетам TCP и UDP или открывать их у себя, принимать и передавать данные через них. Это Unix-утилита, поэтому она не предусмотрена для Windows, однако, вы можете загрузить ее с GitHub.

Открытие сокетов: 
```bash
nc -lvp port        # Открыть порт для прослушивания на своем сетевом интерфейсе
```


Отправка бинарника: 
```bash
nc IP port < file.xlsx           # Отправка бинарного файла на сервер
```
